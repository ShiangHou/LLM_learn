# 交叉熵

## 定义

交叉熵就是说，比如一个分类任务，我预测的是所有种类的概率



对应到大模型上，next token predict，那么所有的种类就是词表V的大小，选一个概率最大的词



简化一下，假设词表大小是V，然后模型在最后一层的输出是

[B,L,H]

即batch大小，sequence长度，hidden隐藏维度

然后会经过一个llm head（比如是一个[H,V]的矩阵)弄到词表上，得到

[B,L,V]

在shift后，对于某一个位置的，V就是他的下一个所有概率的预测，

这样的话，正确位置的token就在V里面固定住了

比如对于一个token，模型预测



简化来说，假设词表是3，那么[0.7,0.2,0.1]是模型输出的概率，然后正确答案就是第一个token

因为是one -hot，所以loss直接就是
$$
L = -\log p_{y}
$$


对应这个例子，直接拿对应正确位置的token的loss去算就行，所以就是$-\log 0.7$就行，大概是0.357，



真正的交叉熵是
$$
H(y,p) = -\sum^{C}_{c = 1} y_c \log p _{c}
$$
因为，我们的真实标签要求，输出某个token的概率直接是1，这样整个词表的label就变成了[1,0,0]，$y_c$就只有一个是正的，而且是1，其他全都是0



然后模型的[0.7,0.2,0.1]这个东西是logits 后softmax，就是attention block后[B,S,H]经过一层，变成[B,S,V]，叫logits，然后再softmax后变成[B,S,V]即概率

## 手撕

先写一个最简单的版本



```python
import torch

def CrossEntropy(logits,target):
  '''
  logits : [B,C] 表示每一个样本在所有位置上的概率
  target:[B] 表示每一个样本的正确的位置是哪一个
  '''
  #先把logits转化成概率
  probs = logits.softmax(logits,dim = -1)
  
  #取出每个样本对应的正确的概率
  batch_indices = torch.arange(logits.size(0))#这里先把B取出来，弄成一个[B的维度下表，如果B是2，那么batch_incies就是[0,1]
  
  correct_probs = probes[batch_indices,target]#注意到，batch_indices就是整个batch的下标，然后targte是整个batch对应的正确值，那么probes就相当于 拿到第batch个的正确答案，假如target是[0,1]那么这里就是probes[[0,1],[0,1]],即probes在第0个batch预测是0de概率，在第1个batch预测是1的概率,这样correct_probs就是一个[B]维度的数，比如[0.8,0,6] 
  
  #算loss
  loss = -torch.log(correct_probs)#得到每个样本的损失
  
  return loss.mean()
  #即返回整个batch的交叉熵损失
  
```

然后这里有几个问题，首先是数值稳定，建议soft max和log一起，


不输入probes，是为了在里面再计算softmax，方便数值稳定

但分开计算时，`softmax` 可能出现上溢或下溢。`log_softmax` 能够利用 log-sum-exp 技巧稳定计算
