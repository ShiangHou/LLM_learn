### 一、 PPO 的完整流程（四大模型交响乐）

在 LLM 的 PPO 训练中，内存里通常需要同时驻留四个模型：

1. **Actor Model (策略模型)**：你要训练的主模型，负责生成回复。
2. **Reference Model (参考模型)**：Actor 的冻结版本，用于计算 KL 散度，防止 Actor 变得“面目全非”（比如为了拿高分变成复读机）。
3. **Reward Model (奖励模型)**：静态打分模型，根据 Prompt 和完整的 Response 给出一个全局标量分数。
4. **Critic Model (价值模型 / Value Model)**：动态更新的模型，负责预测在当前生成到第 $t$ 个 Token 时，**未来**能拿到多少总收益（Expected Return）。

#### 核心步骤：

1. **Rollout (采样阶段)**：Actor 根据输入的 Prompt 逐个 Token 生成完整的 Response。同时，Reference 模型也对这个生成的序列计算每一步的概率。
2. **Reward Estimation (奖励计算)**：完整的序列交给 Reward Model 打分，得到一个标量 $R$。同时，结合 Actor 和 Reference 的概率比，计算每个 Token 位置的即时奖励（包含 KL 惩罚）。
3. **Value & Advantage Estimation (价值与优势估计)**：Critic 模型对每个中间状态进行估值（$V$ 值）。利用 GAE（广义优势估计）算法，从最后一个 Token 往前回推，计算出每个 Token 的优势值（Advantage, $A$）。
4. **Policy Update (策略更新)**：利用算好的 $A$ 值，计算新旧策略的概率比，并使用 **Clip (截断) 机制**限制单次更新的幅度，更新 Actor 的参数；同时利用均方误差（MSE）更新 Critic 的参数。

### 二、 具体样本的 Token 级演算（GAE 推导）

面试官最爱深挖的就是**优势函数是怎么算出来的**。我们假设一个极简的 Case：

- **输入 (Prompt, $x$)**：`"你好"`
- **Actor 生成的回复 (Response, $y$)**：`"世界"`（假设分词为两个 Token：$y_1 = \text{"世"}$, $y_2 = \text{"界"}$）。

我们来看看 PPO 在这个样本上具体做了什么运算：

#### 第 1 步：拿到各家模型的输出值

- **Actor 与 Ref 的概率**：计算每个 Token 生成的 Logits，转化为概率。
- **Critic 的价值预测**：预测当前前缀的未来收益。
  - $V_0 = \text{Critic}(\text{"你好"})$
  - $V_1 = \text{Critic}(\text{"你好 世"})$
  - $V_2 = \text{Critic}(\text{"你好 世界"})$
- **Reward Model 打分**：打分模型只看完整句子，给出最终得分 $R_{\text{final}} = \text{Reward}(\text{"你好 世界"})$。

#### 第 2 步：计算每个步长（Step-level）的即时奖励 $r_t$

环境的真实奖励通常只在最后一步给，但为了防止模型钻空子，我们在每一步都加入 KL 散度作为惩罚：

- **Token 1 ("世")** 的即时奖励：

  $$r_1 = -\beta \log \frac{P_{\text{actor}}(y_1 | x)}{P_{\text{ref}}(y_1 | x)}$$

- **Token 2 ("界")** 的即时奖励（最后一步，加上环境给的最终分数）：

  $$r_2 = -\beta \log \frac{P_{\text{actor}}(y_2 | x, y_1)}{P_{\text{ref}}(y_2 | x, y_1)} + R_{\text{final}}$$

#### 第 3 步：使用 GAE 从后往前计算 Advantage ($A_t$)

Advantage 的物理意义是：**“在当前状态下，采取当前动作（生成当前 Token），比我之前预期的平均表现好多少？”**。大于 0 说明这个 Token 生成得好，要鼓励；小于 0 要抑制。

先计算每一步的 TD Error（时序差分误差） $\delta_t$（假设折扣因子 $\gamma = 1$）：

- **最后一步 $t=2$**（因为后面没有生成了，下一个状态的 $V=0$）：

  $$\delta_2 = r_2 + \gamma \cdot 0 - V_1$$

- **倒数第二步 $t=1$**：

  $$\delta_1 = r_1 + \gamma \cdot V_2 - V_0$$

然后利用 GAE 公式引入平滑系数 $\lambda$ 进行回溯累加计算优势值 $A_t$：

- **Token 2 的优势值**：

  $$A_2 = \delta_2$$

- **Token 1 的优势值**：

  $$A_1 = \delta_1 + \gamma \lambda A_2$$

*(注：计算出 $A_1$ 和 $A_2$ 后，通常还会对整个 Batch 的 Advantage 进行归一化（Normalize），让均值为 0，方差为 1，以保证训练的稳定性。)*

#### 第 4 步：Clip 截断与 Actor 更新

对于 Token $t$（比如 "世"），计算新旧策略的概率比：

$$\text{Ratio}_t = \frac{P_{\text{actor\_new}}(y_t | \dots)}{P_{\text{actor\_old}}(y_t | \dots)}$$

如果没有约束，模型可能会一次更新跨步太大直接崩溃。PPO 的精髓在于把 $\text{Ratio}_t$ 限制在 $[1-\epsilon, 1+\epsilon]$（通常 $\epsilon=0.2$）之间：

$$L_{\text{actor}} = -\min(\text{Ratio}_t \cdot A_t, \text{clip}(\text{Ratio}_t, 1-\epsilon, 1+\epsilon) \cdot A_t)$$

算完这个 Loss，反向传播更新 Actor 即可。
