# 最大为N的数字组合

## 初步思路

题目说，给我们一个数组，里面是1-9之间的数，然后给了我们一个N，问用这些数可以组成多少个小于等于N的数

比如说 1 3 5，然后N是100

这里的组合不是求数，而是就是“组合”，就是11和在一起，就是11，小于100，就可以

那么这里是，所有的两位数都可以，然后还有1位数，

一个很直接的思路是，我们先看需要组成的位数

比如说是3位，那么所有1位和2位的肯定都可以，直接加上

然后是3位的话，一个位数一个位数去看，如果第一位小于N的第一位，那么后面的就可以随便加，如果第一位的和N的第一位一样，那么需要往下比较，


## DP思路

very的复杂啊

整体的就是一个递归

递归我们需要三个变量，一个是i，即滑倒的位数，这个i在N上进行滑动，即从 0-len(N)-1

然后还需要两个bool类型的变量，就是 is_limit和is_num

如果is_limit，说明被咔脖子了（就是前面的已经填的和N一摸一样了）

如果is_num表示前面有没有填过数字（处理单位的情况）


那么我们可以写一个f(i,is_limit,is_num)的递归

首先依旧是写边界，如果i == s的长度，如果is_num，说明之前填过数字，直接返回1就行，相当于是一个钟


然后开始
res = 0
if not is_num:
    res = f(i + 1, False, False)

意思就是，如果is_num是false，说明之前没填，那么我下面的也可以不填

up = s[i] if is_limit else '9'

这个是确认当前最大可以填多少，如果is_limit，说明之前填过位，那么当前的最大就只能是N当前位的最大，如果之前有没填的，说明位数小，那么可以放肆的填，上限就是9

for d in digits:
    if d > up: break
开始填，遍历我们的sigits，如果大于上限，直接跳出，为什么是跳出？因为digits是排好序的，如果d不行，那么d后面的肯定也不行

res += f(i + 1, is_limit and d == up, True)

这个就是，走完了这一位，然后递归，走下一位，看三个入参数

i就是i+1
is_limit and d == up 这个是说，只有当    之前的是达到了limit，并且当前填的d也是达到了上限，这样就说明上限传递下去了，传到了下一位

True  这个好理解，就是我们填数字了
