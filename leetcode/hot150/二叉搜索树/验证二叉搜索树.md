# 验证二叉搜索树
给你一个二叉树的根节点 root ，判断其是否是一个有效的二叉搜索树。

有效 二叉搜索树定义如下：

节点的左子树只包含 严格小于 当前节点的数。
节点的右子树只包含 严格大于 当前节点的数。
所有左子树和右子树自身必须也是二叉搜索树。

## 初步思路
在递归的时候带着两个，一个是最小的，一个是最大的

最小的定义为无穷大，最大的定义为无穷小

然后往下走的时候，走左边，把当前的node.val递归到下一层的最大就行，走右边吧当前的递归到下一层的最小就行

如果发现有的node不在最大和最小的范围，直接return False就可以


```python 
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        def f(node,l,r):
            if not node:
                return True
            if node.val<=l or node.val >= r:#超过了
                return False
            else:#没超过
                return f(node.left,l,min(r,node.val)) and f(node.right,max(l,node.val),r)
        return f(root,float('-inf'),float('inf'))
        
        
```
