# 单词搜索
给定一个 m x n 二维字符网格 board 和一个字符串单词 word 。如果 word 存在于网格中，返回 true ；否则，返回 false 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。


## 初步思路
bfs，我们首先从一个点开始，然后看前后左右，越界或者不等于word k的都返回false

相等的话，需要标记一下用过了，然后dfs开始i前后左右递归，用or来，记得把标记过的返回过来就行

```python 
class Solution(object):
    def exist(self, board, word):
        n,m = len(board),len(board[0])
        def dfs(i,j,k):#k是单词滑动，i和j是在board上滑动
            if k  == len(word):#到头了
                return True
            if i < 0 or i > n-1 or j <0 or j > m-1 or board[i][j] != word[k]:
                return False
            temp = board[i][j]
            board[i][j] = "#"
            ans = dfs(i+1,j,k+1) or dfs(i-1,j,k+1) or dfs(i,j+1,k+1) or dfs(i,j-1,k+1)
            board[i][j] = temp
            return ans
        for i in range(n):
            for j in range(m):
                if dfs(i,j,0):
                    return True
        return False

```
