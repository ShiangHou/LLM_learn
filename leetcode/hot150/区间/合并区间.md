# 合并区间

以数组 intervals 表示若干个区间的集合，其中单个区间为 intervals[i] = [starti, endi] 。请你合并所有重叠的区间，并返回 一个不重叠的区间数组，该数组需恰好覆盖输入中的所有区间 。

 

示例 1：

输入：intervals = [[1,3],[2,6],[8,10],[15,18]]
输出：[[1,6],[8,10],[15,18]]
解释：区间 [1,3] 和 [2,6] 重叠, 将它们合并为 [1,6].
示例 2：

输入：intervals = [[1,4],[4,5]]
输出：[[1,5]]
解释：区间 [1,4] 和 [4,5] 可被视为重叠区间

## 初步思路

首先需要对这些个区间按照left的元素的大小进行排序

排序完后，对于每一个，区间，比较right和left的大小，如果right是大于left，合并，新的right是max(right,right)两个区间的右边的最大的，然后继续

思想依旧是合并到不能合并，加入答案，然后下一个

```python 
class Solution:
    def merge(self, intervals: List[List[int]]) -> List[List[int]]:
        #首先先排序
        intervals.sort(key = lambda x: x[0])
        n = len(intervals)
        i = 0
        ans = []
        while i < n:
            begin = intervals[i][0]
            end = intervals[i][1]
            while i+1 < n and intervals[i][1] >= intervals[i+1][0]:
                intervals[i+1][1] = max(intervals[i][1],intervals[i+1][1])
                end = intervals[i+1][1]
                i+=1
            #找到后，将这个加入,然后i到下一个
            ans.append([begin,end])
            i+=1
        return ans
```
