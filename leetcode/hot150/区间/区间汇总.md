# 区间汇总
给定一个  无重复元素 的 有序 整数数组 nums 。

区间 [a,b] 是从 a 到 b（包含）的所有整数的集合。

返回 恰好覆盖数组中所有数字 的 最小有序 区间范围列表 。也就是说，nums 的每个元素都恰好被某个区间范围所覆盖，并且不存在属于某个区间但不属于 nums 的数字 x 。

列表中的每个区间范围 [a,b] 应该按如下格式输出：

"a->b" ，如果 a != b
"a" ，如果 a == b
 

示例 1：

输入：nums = [0,1,2,4,5,7]
输出：["0->2","4->5","7"]
解释：区间范围是：
[0,2] --> "0->2"
[4,5] --> "4->5"
[7,7] --> "7"

## 初步思路

这里面很显然是要求连续的

看下题目，题目给的就已经是有序的了

那么我们直接写，从下标0开始，记录begin，如果+1在，就继续，不在的话就跳出统计一下

```python 
class Solution:
    def summaryRanges(self, nums: List[int]) -> List[str]:
        ans = []
        n = len(nums)
        i = 0
        while i < n:
            begin = i
            end = i
            while i+1 <n and nums[i+1] == nums[i]+1:
                i = i+1
                end = i
            #统计答案
            if begin != end:
                ans.append(f"{nums[begin]}->{nums[end]}")
            else:
                ans.append(f"{nums[i]}")
            i = i+1
        return ans 

```
