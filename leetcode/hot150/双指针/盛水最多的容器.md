# 盛水最多的容器
给定一个长度为 n 的整数数组 height 。有 n 条垂线，第 i 条线的两个端点是 (i, 0) 和 (i, height[i]) 。

找出其中的两条线，使得它们与 x 轴共同构成的容器可以容纳最多的水。

返回容器可以储存的最大水量。

说明：你不能倾斜容器。

## 初步思路
依旧是左右两个指针，从0和n-1开始，然后统计一下能装多少，然后比较左右谁小，谁小就谁+1，用一个max去每次更新答案

```python 
class Solution:
    def maxArea(self, height: List[int]) -> int:
        l,r = 0,len(height)-1
        ans = float('-inf')
        while l<r:
            min_height = min(height[l],height[r])

            ans = max(ans,(r-l)*min_height)
            if min_height==height[l]:
                l+=1
            else:
                r-=1
        return ans



```
