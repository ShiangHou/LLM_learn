# 验证回文串

如果在将所有大写字符转换为小写字符、并移除所有非字母数字字符之后，短语正着读和反着读都一样。则可以认为该短语是一个 回文串 。

字母和数字都属于字母数字字符。

给你一个字符串 s，如果它是 回文串 ，返回 true ；否则，返回 false 。

 

示例 1：

输入: s = "A man, a plan, a canal: Panama"
输出：true
解释："amanaplanacanalpanama" 是回文串。

## 初步思路

思路就是说，我把这个字符串清晰干净，然后和::-1一样，就说嘛是的

或者双指针也可以，遇到不是字母的+1，是字母的low一下

python判断一个字符串是不是字母是s.isalpha()

转为小写是text.lower()

```python 
class Solution:
    def isPalindrome(self, s: str) -> bool:
        n = len(s)
        l,r = 0,n-1
        while l<r:
            if not s[l].isalpha():
                l+=1
                continue
            elif not s[r].isalpha():
                r-=1
                continue
            else:#都不是，说明都是字母
                if s[l].lower() != s[r].lower():
                    return False
                else:
                    l+=1
                    r-=1
        return True

```
