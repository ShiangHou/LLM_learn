# 长度最小的子数组

给定一个含有 n 个正整数的数组和一个正整数 target 。

找出该数组中满足其总和大于等于 target 的长度最小的 子数组 [numsl, numsl+1, ..., numsr-1, numsr] ，并返回其长度。如果不存在符合条件的子数组，返回 0 。

 

示例 1：

输入：target = 7, nums = [2,3,1,2,4,3]
输出：2
解释：子数组 [4,3] 是该条件下的长度最小的子数组。

## 初步思路
这里说的是子数组，不是子序列，子数组要连续才行

所以卡一个滑动窗口，每次只要小就往后加，大的话就l缩，等于的话就统计一下，然后往前加、
仔细看题，这里说是大于等于targte的就行

所以一个快慢指针，然后快的一直往前冲，小的话就加，大的话统计，然后缩一下慢的就行
缩的时候一直缩到小鱼等的
```python 
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        n = len(nums)
        s,f = 0,0
        temp_sum = 0
        ans = float('inf')
        while f<n:
            temp_sum+=nums[f]
            while temp_sum >=target:
                ans = min(ans,f-s+1)
                temp_sum-=nums[s]
                s+=1
            f+=1

        return ans if ans != float('inf') else 0

```
