# 串联所有单词的子串

给定一个字符串 s 和一个字符串数组 words。 words 中所有字符串 长度相同。

 s 中的 串联子串 是指一个包含  words 中所有字符串以任意顺序排列连接起来的子串。

例如，如果 words = ["ab","cd","ef"]， 那么 "abcdef"， "abefcd"，"cdabef"， "cdefab"，"efabcd"， 和 "efcdab" 都是串联子串。 "acdbef" 不是串联子串，因为他不是任何 words 排列的连接。
返回所有串联子串在 s 中的开始索引。你可以以 任意顺序 返回答案。

 

示例 1：

输入：s = "barfoothefoobarman", words = ["foo","bar"]
输出：[0,9]
解释：因为 words.length == 2 同时 words[i].length == 3，连接的子字符串的长度必须为 6。
子串 "barfoo" 开始位置是 0。它是 words 中以 ["bar","foo"] 顺序排列的连接。
子串 "foobar" 开始位置是 9。它是 words 中以 ["foo","bar"] 顺序排列的连接。
输出顺序无关紧要。返回 [9,0] 也是可以的。
示例 2：

输入：s = "wordgoodgoodgoodbestword", words = ["word","good","best","word"]
输出：[]
解释：因为 words.length == 4 并且 words[i].length == 4，所以串联子串的长度必须为 16。
s 中没有子串长度为 16 并且等于 words 的任何顺序排列的连接。
所以我们返回一个空数组。

如果遇到一个不是set里面的，那么

哎不对，这样其实会遇到有重复的，

所以这样，首先我们需要维护words每个单词出现了几次，用一个dict去维护

然后我们copy一个滑动窗口的dict，次数空着

每次开始快慢指针遍历，而且不能直接切s，会有比去abab这样的ba的出线，还是要自己切

那么此时会有三种情况

一种是遇到了没出现过的单词，此时直接清理掉window，然后slow==fast

一种是遇到了多个单词，超了，此时不断移动left，直到正常

一种是正好等于，统计

```python 
class Solution:
    def findSubstring(self, s: str, words: List[str]) -> List[int]:
        from collections import Counter,defaultdict
        if not s or not words:
            return []
        word_count = len(words)#有几个单词
        word_len = len(words[0])#单词长度
        need = Counter(words)#每个单词出现了多少次

        ans = []

        for offset in range(word_len):
            l,r = offset,offset
            #当前窗口每个窗口出现的数字
            window = defaultdict(int)

            #当前窗口有多少个单词
            current_count = 0

            while r+word_len<=len(s):
                #读右边一个完整的单词
                word = s[r:r+word_len]
                r += word_len
                if word not in need:#如果当前的单词不在这
                    window.clear()#清空
                    current_count = 0
                    l = r
                    continue
                #把当前的单词加入到窗口
                window[word]+=1
                current_count +=1

                while window[word] > need[word]:#超了
                    l_word = s[l:l+word_len]
                    window[l_word] -=1
                    l+=word_len
                    current_count -=1
                #窗口里正好有
                if current_count == word_count:
                    ans.append(l)
                    #移除左边的，继续找
                    l_word= s[l:l+word_len]
                    window[l_word] -= 1
                    l+=word_len
                    current_count-=1
        return ans
```
