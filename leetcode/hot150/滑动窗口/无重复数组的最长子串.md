# 无重复数组的最长子串
给定一个字符串 s ，请你找出其中不含有重复字符的 最长 子串 的长度。

 
示例 1:

输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。

## 初步思路
思路也是滑动，准备一个set，新加一个，如果不在set里面，就直接加，统计长度，如果在set里面，就缩，缩的时候注意，如果和新来的一样，就缩玩就停，如果不一样，还要继续索

```python 
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        cache = set()
        ans = 0
        slow,f = 0,0
        while f <len(s):
            if s[f] not in cache:
                cache.add(s[f])
                f+=1
                ans = max(ans,f-slow+1)
            else:
                cache.remove(s[slow])
                slow+=1
                
        return ans
```
