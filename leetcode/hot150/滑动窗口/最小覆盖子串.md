# 最小覆盖子串
给定两个字符串 s 和 t，长度分别是 m 和 n，返回 s 中的 最短窗口 子串，使得该子串包含 t 中的每一个字符（包括重复字符）。如果没有这样的子串，返回空字符串 ""。

测试用例保证答案唯一。

 

示例 1：

输入：s = "ADOBECODEBANC", t = "ABC"
输出："BANC"
解释：最小覆盖子串 "BANC" 包含来自字符串 t 的 'A'、'B' 和 'C'。
## 初步思路
首先这个和之前的滑动窗口差不多，两个快慢指针往前冲，如果遇到了就加，到了就判断，后面就缩

然后有几个细节
我们首先将t弄成dict和数字表示出现了几次，然后去判断有没有覆盖掉


```python 
class Solution:
    def minWindow(self, s: str, t: str) -> str:
        from collections import Counter
        counter_s = Counter()#s出现的次数
        counter_t = Counter(t)#t出现的次数

        ans_left,ans_right = -1,len(s)

        left = 0
        for right,c in enumerate(s):
            counter_s[c] +=1#统计一下
            while counter_s >=counter_t:#如果涵盖了
                if right-left < ans_right-ans_left:#如果这是一个更好的答案
                    ans_right,ans_left = right,left
                #移走左边的
                counter_s[s[left]]-=1
                left+=1
        return "" if ans_left == -1 else s[ans_left:ans_right+1]
                
```

这里其实不是最优，因为有这个counter_s >=counter_t

这个比较是说，比的是次数，如果一个字典里面的是次数是高于另一个出现的次数的时候，那么就算大于等于

优化的话，我们可以用一个变量vaild来取优化，不用每次都比一遍，之前写的就行
