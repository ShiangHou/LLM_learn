# 最后一个单词的长度

给你一个字符串 s，由若干单词组成，单词前后用一些空格字符隔开。返回字符串中 最后一个 单词的长度。

单词 是指仅由字母组成、不包含任何空格字符的最大子字符串。

## 初步思路

感觉就是，按照空格切分，存在list里面，然后返回最后一个？用split

```python 
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        str_ist = list(map(str,s.strip().split(' ')))
        return len(str_ist[-1])
```

额，其实不能用split，应该从后往前遍历就行，最后统计的也是长度，遇到空格或者到头了后就直接终止

```python 
class Solution:
    def lengthOfLastWord(self, s: str) -> int:
        n = len(s)
        index = n-1
        ans = 0
        #先要找到最后一个的下标在哪
        while s[index] == " ":
            index -=1
 
        #现在index是最后一个字母
        while index >=0:#这里是大于等于0
            if s[index] == " ":
                return ans
            index -=1
            ans +=1
        return ans#这里是ans
```

好几个边界条件，一个是a，一个是" a" 一个是"a "
