# 除自身之外的乘积

## 题目描述
给你一个整数数组 nums，返回 数组 answer ，其中 answer[i] 等于 nums 中除了 nums[i] 之外其余各元素的乘积 。

题目数据 保证 数组 nums之中任意元素的全部前缀元素和后缀的乘积都在  32 位 整数范围内。

请 不要使用除法，且在 O(n) 时间复杂度内完成此题。

 
## 初步思路

首先是要求n，自然是想到了，我需要过一遍数组，或者过两边数组就可以


比如 1 2 3 4 5 

以2为例，假设有两个数组，一个记录了自己前面所有人的乘积，一个记录了自己以后所有人的乘积，那么2这个位置的答案就是这两个相乘就行

因为不允许使用除法，所以只能卡住自己就行，也就是前缀的0位置弄成-1，后缀的n-1位置弄成-1就行

```python 
class Solution:
    def productExceptSelf(self, nums: List[int]) -> List[int]:
        n = len(nums)
        pre_time = [0]*n
        pre_time[0] = nums[0]

        
        tail_time = [0]*n
        tail_time[-1] = nums[-1]

        ans = [-1]*n
        for i in range(1,n):
            if i == 1:
                pre_time[i] = pre_time[0]
            else:
                pre_time[i] = pre_time[i-1]*nums[i-1]
        for i in range(n-2,-1,-1):
            if i == n-2:
                tail_time[i] = tail_time[i+1]
            else:
                tail_time[i] = tail_time[i+1]*nums[i+1]

        ans[0] = tail_time[0]
        ans[-1] = pre_time[-1]
        for i in range(1,n-1):
            ans[i]=tail_time[i]*pre_time[i]
        return ans
            

```
