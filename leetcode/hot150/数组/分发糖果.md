# 分发糖果

## 题目描述
n 个孩子站成一排。给你一个整数数组 ratings 表示每个孩子的评分。

你需要按照以下要求，给这些孩子分发糖果：

每个孩子至少分配到 1 个糖果。
相邻两个孩子中，评分更高的那个会获得更多的糖果。
请你给每个孩子分发糖果，计算并返回需要准备的 最少糖果数目 。

## 初步思路
这题貌似做过，先从左往右，在从右往左，右往左的时候比较一下，取最小的就行

```python 
class Solution:
    def candy(self, ratings: List[int]) -> int:
        n = len(ratings)
        ans = [1]*n

        for i in range(1,n):
            if ratings[i]>ratings[i-1]:
                ans[i] = ans[i-1]+1
        
        for i in range(n-2,-1,-1):
            if ratings[i]>ratings[i+1]:
                ans[i] = ans[i+1]+1 if ans[i]<=ans[i+1] else ans[i]#看一下是不是本来就比你大，不然不需要加
        return sum(ans)

```
