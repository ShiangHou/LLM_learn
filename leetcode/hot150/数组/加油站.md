# 加油站

## 题目描述
在一条环路上有 n 个加油站，其中第 i 个加油站有汽油 gas[i] 升。

你有一辆油箱容量无限的的汽车，从第 i 个加油站开往第 i+1 个加油站需要消耗汽油 cost[i] 升。你从其中的一个加油站出发，开始时油箱为空。

给定两个整数数组 gas 和 cost ，如果你可以按顺序绕环路行驶一周，则返回出发时加油站的编号，否则返回 -1 。如果存在解，则 保证 它是 唯一 的。

## 初步思路

很显然，这题应该是要用On的复杂度

我们的目标是，能够选择一个作为起点来去弄

那么首先，如果sum后 的cost是大于gas的，那么肯定不可以，直接返回-1就行（相当于遍历了一遍，无所谓）

紧接着我们需要确认一个起点

这里的思想是，如果已经在谷底了，怎么走都是向上的

由于我们刚才已经pass掉了cost是大于gas，那么如果gas是大于cost的话，说明一定是有解的

我们连起来，找到谷低就行，即油量最低时候的加油站

即我们去模拟路径，计算出最小的油量（就假设从0开始就行了，不管cost是不是小于在走，一直走就行）

```python 
class Solution:
    def canCompleteCircuit(self, gas: List[int], cost: List[int]) -> int:
        if sum(gas) < sum(cost):
            return -1
        n = len(gas)
        ans = 0
        _min = float('inf')#这个是最小油量
        s = 0#这个是油量
        for i in range(n):
            s += gas[i]-cost[i]
            if s <_min:
                ans = i+1#减去后汽车是在i+1
                _min = s
        return ans if ans < n else 0#边界条件防止是最后一个



```
