# 移除元素

## 初步思路
题目说的很抽象，但很简单，就是原地把元素移除，然后依次往上补上去就行

依旧是双指针

```python 
class Solution:
    def removeElement(self, nums: List[int], val: int) -> int:
        #搞一个指针，一次遍历。
        #指针指向前k个不包含val的下面的位置
        #再往后遍历的时候，如果不是val，直接和指针的位置交换就行，然后继续
        k = 0
        for i in range(len(nums)):
            if nums[i] != val:
                nums[k],nums[i] = nums[i],nums[k]
                k+=1
        return k


```
