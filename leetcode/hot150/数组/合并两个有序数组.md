# 合并两个有序数组

## 初步思路
给你两个按 非递减顺序 排列的整数数组 nums1 和 nums2，另有两个整数 m 和 n ，分别表示 nums1 和 nums2 中的元素数目。

请你 合并 nums2 到 nums1 中，使合并后的数组同样按 非递减顺序 排列。

这个思路很好想，直接两个指针，就行

```python 
class Solution:
    def merge(self, nums1: List[int], m: int, nums2: List[int], n: int) -> None:
        """
        Do not return anything, modify nums1 in-place instead.
        """
        #这个不能开额外空间，但是题目中已经帮我们把nums1的额外空间开好了，所以直接比较大的，对于num1的来说，用两个指针进行交换，对于nums2，也是直接替换就行
        l1,l2 = m-1,n-1#不断往前滑动的
        cur = m+n-1#填最终的
        while l1 >= 0 and l2 >=0:
            #谁大谁放在cur，然后-1
            if nums1[l1] >= nums2[l2]:
                nums1[cur] = nums1[l1]
                l1 -= 1
                
            else:
                nums1[cur] = nums2[l2]
                l2 -= 1
            cur -= 1
        #如果是m那个走到了头，n那个还没走到头，就需要把n的全部放在头部，n走到头的话就不用管了
        while l2 >=0:
            nums1[cur] = nums2[l2]
            l2 -=1
            cur -=1
            


```
