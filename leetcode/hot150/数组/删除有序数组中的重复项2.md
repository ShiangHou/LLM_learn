# 删除有序数组种的重复项2

## 初步思路

给你一个有序数组 nums ，请你 原地 删除重复出现的元素，使得出现次数超过两次的元素只出现两次 ，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在 原地 修改输入数组 并在使用 O(1) 额外空间的条件下完成。

```python 
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        #原地修改，肯定是用指针，
        #维护一个k是最终的答案，对于遍历来的i，如果发现它和倒数第二的元素是一样的，说明它是第三个，就不管他，如果不一样，直接把它换到k的位置，然后k往后推就行
        k = 2#默认前两个都可以
        for i in range(2,len(nums)):
            #如果i等于nums[k-2]的位置（即k是长度，k-1是最后一个的下标，k-2是倒数第二个），那么说明i是第三个，直接不要，继续遍历
            if nums[i] == nums[k-2]:
                continue
            else:
                nums[k] = nums[i]#k-1是下标，k正好是后一个
                k+=1
        return k
            

```
