# 删除有序数组的重复项

## 初步思路
和移除元素差不多，这里两个指针，相当于是一直把不一样的往前放就行，

```python 
class Solution:
    def removeDuplicates(self, nums: List[int]) -> int:
        #和上一题一样，构建一个，
        #让往后遍历的时候看一下和k位置的大小就行
        k = 1
        for i in range(1,len(nums)):
            if nums[i]> nums[k-1]:
                nums[i],nums[k] = nums[k],nums[i]
                k+=1
        return k
```
