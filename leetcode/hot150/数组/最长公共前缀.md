# 最长公共前缀
编写一个函数来查找字符串数组中的最长公共前缀。

如果不存在公共前缀，返回空字符串 ""。

示例 1：

输入：strs = ["flower","flow","flight"]
输出："fl"

## 初步思路

额，这个取每一个位置的0然后比较，直到不一样或者有一个是不存在的，那么暂停就行？？

不过最好是把这些搞成一个hash，这样取的时候不用遍历

搞成hash也不行，其实还是要strs[i][j]这样去比较

就是说，我们先竖着遍历，遍历完再横着遍历

相当于，我们先拿一个str，比如第0个，然后开始横着遍历，如果遇到和第0个不一样的，直接返回就行，

```python 
class Solution:
    def longestCommonPrefix(self, strs: List[str]) -> str:
        s0 = strs[0]
        #从左往右
        for j,c in enumerate(s0):#这里j是下标，然后c是内容
            #从上往下
            for s in strs:
                if j == len(s) or s[j] != c:#如果有一个的已经到头了，或者说不等于选的那个的位置
                    return s0[:j]#直接输出到j就行
        return s0
            


```
