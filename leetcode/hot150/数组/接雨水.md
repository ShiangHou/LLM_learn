# 接雨水

## 题目描述

给定 n 个非负整数表示每个宽度为 1 的柱子的高度图，计算按此排列的柱子，下雨之后能接多少雨水。

## 初步思路

思路是找到每一个的最右边的最小，和最左边的最小，然后再取min

双指针写法，记得

```python 
class Solution:
    def trap(self, height: List[int]) -> int:
        left_max = 0
        right_max = 0
        n = len(height)
        l,r = 0,n-1
        ans = 0
        while l <r:
            left_max = max(left_max,height[l])
            right_max = max(right_max,height[r])
            if left_max<= right_max:
                #更新左
                ans += left_max-height[l]#这里是用左-左
                l+=1
            else:
                ans += right_max-height[r]#这里是右-右
                r-=1
        return ans 



```
