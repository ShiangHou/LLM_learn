# 文本左右对齐
给定一个单词数组 words 和一个长度 maxWidth ，重新排版单词，使其成为每行恰好有 maxWidth 个字符，且左右两端对齐的文本。

你应该使用 “贪心算法” 来放置给定的单词；也就是说，尽可能多地往每行中放置单词。必要时可用空格 ' ' 填充，使得每行恰好有 maxWidth 个字符。

要求尽可能均匀分配单词间的空格数量。如果某一行单词间的空格不能均匀分配，则左侧放置的空格数要多于右侧的空格数。

文本的最后一行应为左对齐，且单词之间不插入额外的空格。

例子
示例 1:

输入: words = ["This", "is", "an", "example", "of", "text", "justification."], maxWidth = 16
输出:
[
   "This    is    an",
   "example  of text",
   "justification.  "
]
示例 2:

输入:words = ["What","must","be","acknowledgment","shall","be"], maxWidth = 16
输出:
[
  "What   must   be",
  "acknowledgment  ",
  "shall be        "
]
解释: 注意最后一行的格式应为 "shall be    " 而不是 "shall     be",
     因为最后一行应为左对齐，而不是左右两端对齐。       
     第二行同样为左对齐，这是因为这行只包含一个单词。
示例 3:

输入:words = ["Science","is","what","we","understand","well","enough","to","explain","to","a","computer.","Art","is","everything","else","we","do"]，maxWidth = 20
输出:
[
  "Science  is  what we",
  "understand      well",
  "enough to explain to",
  "a  computer.  Art is",
  "everything  else  we",
  "do                  "
]
 

## 初步思路
md先解释一遍题目，

就是要放单词，一行不能超过max个
比如max是16

单词和单词之间必须要算一个空格

比如

This     4

is       2

an       2

这样两个和两个之间就是 4+1+2+1+2，10个，即 “This_is_an"就是10，如果下一个单词是example，这个放进去就是
"this_is_an_example"超过16了，就不能放example在第一行了，所以第一行要是This_is_an

但它也没满16，所以此时要把空格补上去

如果是偶数，就对称补上，比如这里是少6个，然后有两个可以放的，所以就是每个地方放三个就行，即

"This___is___an"

如果除不尽的话，优先放在左边

如果这一行只有一个单词，或者是最后一行，那么需要把这个单词左对齐，剩下的都放在右边，比如

"example________"

所以应该是要分两步

首先是统计当前的单词长度+必须的空格+下一个单词的长度是不是超过了max。如果没超过的话直接加进来

如果超过了，那么就要开始把多余的空格塞进去
如果只有一个单词或者是最后一行，就直接左对齐
否则的话，平均分配空格，余的放左边

```python 
class Solution:
    def fullJustify(self, words: List[str], maxWidth: int) -> List[str]:
      result = []
      n = len(words)
      i = 0

      while i<n:#外层循环，统计能不能放下一个单词
        word_length = len(words[i])

        j = i+1#j是下一个将要加入的

        while j <n:
          required_length = (word_length+ j-i+len(words[j]))
          if required_length > maxWidth:#如果超过了，这个就不能加，直接break第二个循环
            break
          else:
            #继续加
            word_length += len(words[j])
            j+=1
        
        #第二步，在要处理一行的空格怎么放了
        #当前的是words[i:j](不包含j)，一共有j-i个单词，需要j-i-1个基础的空格，可分配空格是len(words[i]-words[j]的长度+j-i-1和 maxWidth的差)
        word_count = j-i
        is_last_line = j==n
        if word_count == 1 or is_last_line:#如果只有一个单词，或者最后一行
          line = " ".join(words[i:j])
          line += " "*(maxWidth-len(line))
        else:#多个单词，需要考虑分空格了
          total_space = maxWidth-word_length#一共有这么多空格
          gap_count = word_count-1#需要放在这些地方
          space_per_count = total_space // gap_count#一个地方需要放这么多

          extra_space = total_space % gap_count#多出来的

          line_part = []
          #写一个循环，往里面塞单词和空格以及额外的空格，exttra的空格正好从左往右塞，塞完后减少就行
          for k in range(i,j-1):
            line_part.append(words[k])#先塞单词
            #多余的放在左边间隙
            if k == i:#最左边的
              line_part.append(" "*(extra_space+space_per_count))
            else:#不是最左边的，直接正常放
              line_part.append(" "*(space_per_count))
          #最后一个后面不能放空格
          line_part.append(words[j-1])
          line = "".join(line_part)
        result.append(line)
        i = j
      return result

```
