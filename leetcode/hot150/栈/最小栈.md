# 最小栈

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最小元素的栈。

实现 MinStack 类:

MinStack() 初始化堆栈对象。
void push(int value) 将元素 value 推入堆栈。
void pop() 删除堆栈顶部的元素。
int top() 获取堆栈顶部的元素。
int getMin() 获取堆栈中的最小元素。
 

示例 1:

输入：
["MinStack","push","push","push","getMin","pop","top","getMin"]
[[],[-2],[0],[-3],[],[],[],[]]

## 初步思路

读题，这里要求的几个方法都是和普通的栈是一样的，唯一不同的是有一个方法要求获取栈中的最小的元素，

初步思路是，在准备一个栈，这个栈的元素是一一对应的关系

比如压入的顺序分别是 3 5 2 1，最后1在栈顶

开始压3的时候，我们另外准备一个栈，这个栈用来记录当前位置以及之前的最小值

比如开始压入了3，那么最小栈就是3，压入了5，用5和最小栈顶比较，如果没有人家小，直接还是3

此时最小栈就是3 3，对应原来的栈就是3 5

如果来了一个2，那么和最小栈顶比较，发现小，那么直接把2本身压进去，

假设后面2被弹出来了，那么也就是直接在最小栈顶把2弹出就行


```python 
class MinStack:

    def __init__(self):
        #初始构建两个stack
        self.stack = []
        self.min_stack = []

    def push(self, value: int) -> None:#压入的时候，stack正常压入，min_stack
        #压入的时候，stack正常压入，min_stack先和[-1]比较，没有比过的话正常压入
        self.stack.append(value)
        if not self.min_stack:#如果还没有最小的，直接压入
            self.min_stack.append(value)
        else:#先拿到最小的，然后压入
            min_value = min(self.min_stack[-1],value)
            self.min_stack.append(min_value)

    def pop(self) -> None:
        #弹出顶就行
        self.stack.pop()
        self.min_stack.pop()

    def top(self) -> int:
        return self.stack[-1]

    def getMin(self) -> int:
        return self.min_stack[-1]
```
