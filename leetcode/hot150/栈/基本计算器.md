# 基本计算器

给你一个字符串表达式 s ，请你实现一个基本计算器来计算并返回它的值。

注意:不允许使用任何将字符串作为数学表达式计算的内置函数，比如 eval() 。

 

示例 1：

输入：s = "1 + 1"
输出：2
示例 2：

输入：s = " 2-1 + 2 "
输出：3
示例 3：

输入：s = "(1+(4+5+2)-3)+(6+8)"
输出：23

## 初步思路
没有括号的话很好弄，而且这里是只有加法和减法

假设没有括号，那么这个和之前的那个加减乘除是一样的

有的括号的话，遇到左括号就正常压进去，遇到右括号，就需要先把他弄出来，然后再算

可以考虑弄两个栈，一个存数字，一个存符号

题解是一个叫做所谓的括号展开

意思就是说捏，我们想要消除所有的括号，所以在遇到括号前需要看一下括号前的正负
如果是正的，那么后面括号里的东西可以原封不动
如果是负的，那么括号里的东西就要全部变成负

所以首先需要准备一个ops，这个是栈，初始状态是1，然后还有一个sing是1初始的时候



```python 
class Solution:
    def calculate(self, s: str) -> int:
        n = len(s)
        ops = [1]#记录栈里面的符号
        sign = 1#动态迭代每次便利的符号
        i = 0
        ans = 0
        while i <n:
            if s[i] == " ":
                i+=1
            elif s[i] == '+':#遇到+，就是ops最后一个符号不变就行
                sign = ops[-1]
                i+=1
            elif s[i] == '+':#遇到-，就是ops最后一个符号变就行
                sign = -ops[-1]
                i+=1
            elif s[i] == '(':#此时需要处理ops，需要我们吧sign加入到ops中村一下
                ops.append(sign)
                i+=1
            elif s[i] == ')':#此时一波已经处理过了，直接pop出当前括号就行
                ops.pop()
                i+=1
            else:#处理数字
                num = 0
                while i < n and s[i].isdigit():
                    #i是一个位置，这里是诸位读取出数字，用ascii一直加，比如123就是1，1*10+2=12，12*10+3=123
                    num = num*10 + ord(s[i])-ord('0')
                    i+=1
                #拿到数字后，直接和,符号是当前的符号
                ans += num*sign
        return ans

```
