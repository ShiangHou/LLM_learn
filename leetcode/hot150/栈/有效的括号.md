# 有效的括号

给定一个只包括 '('，')'，'{'，'}'，'['，']' 的字符串 s ，判断字符串是否有效。

有效字符串需满足：

左括号必须用相同类型的右括号闭合。
左括号必须以正确的顺序闭合。
每个右括号都有一个对应的相同类型的左括号。
 

示例 1：

输入：s = "()"

输出：true

## 初步思路
最简单的一个栈的应用

准备一个栈，然后遇到左括号就往里面加，遇到右括号就弹出，

遇到右括号的时候，如果弹出的不是对应匹配的左括号，那么直接return false。如果最后stack还不是空的，也return false

```python 
class Solution:
    def isValid(self, s: str) -> bool:
        stack = []
        for i in s:
            if i == "[" or i == "(" or i == "{" :
                stack.append(i)
            else:#是一个右括号
                if not stack:#如果里面没东西，也是非法的
                    return False
                candiate = stack[-1]
                if (i == "]" and candiate == "[") or (i == ")" and candiate == "(") or (i == "}" and candiate == "{"):#是合法的
                    stack.pop()
                else:#非法
                    return False
        return True if not stack else False#没出完也是非法
                    


```
