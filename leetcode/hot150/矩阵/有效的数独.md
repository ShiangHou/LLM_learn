# 有效的数独
请你判断一个 9 x 9 的数独是否有效。只需要 根据以下规则 ，验证已经填入的数字是否有效即可。

数字 1-9 在每一行只能出现一次。
数字 1-9 在每一列只能出现一次。
数字 1-9 在每一个以粗实线分隔的 3x3 宫内只能出现一次。（请参考示例图）
 

注意：

一个有效的数独（部分已被填充）不一定是可解的。
只需要根据以上规则，验证已经填入的数字是否有效即可。
空白格用 '.' 表示。

输入：board = 
[["5","3",".",".","7",".",".",".","."]
,["6",".",".","1","9","5",".",".","."]
,[".","9","8",".",".",".",".","6","."]
,["8",".",".",".","6",".",".",".","3"]
,["4",".",".","8",".","3",".",".","1"]
,["7",".",".",".","2",".",".",".","6"]
,[".","6",".",".",".",".","2","8","."]
,[".",".",".","4","1","9",".",".","5"]
,[".",".",".",".","8",".",".","7","9"]]
输出：true

## 初步思路

额，

嗷嗷，这个只需要判断现在已经填入的数字是否符合数独条件就行了

构建三个，一个row_box[i][x]，bool类型，表示第i行有没有出现x
一个col_box[j][x],bool类型，表示第j列有没有出现x

一个gong_bodex[i'][j'][x]表示第几个宫有没有出现x

对于宫，用i//3来去表示，比如i=8，就是2，即第二个宫（从0开始）

```python 
class Solution:
    def isValidSudoku(self, board: List[List[str]]) -> bool:
        row_box = [[False]*9 for _ in range(9)]
        clo_box = [[False]*9 for _ in range(9)]
        gong_box = [[[False]*9 for _ in range(3)]for _ in range(3)]

        for i ,row in enumerate(board):
            for j, col in enumerate(row):
                if col == ".":
                    continue
                if row_box[i][int(col)-1] == True or clo_box[j][int(col)-1] == True or gong_box[i//3][j//3][int(col)-1] == True:#如果在一行或者一列或者一宫出现过：
                    return False
                #都没出现过，统计一下
                row_box[i][int(col)-1] =  clo_box[j][int(col)-1] = gong_box[i//3][j//3][int(col)-1] = True
        return True


```
