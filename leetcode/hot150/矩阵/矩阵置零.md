# 矩阵置零
给定一个 m x n 的矩阵，如果一个元素为 0 ，则将其所在行和列的所有元素都设为 0 。请使用 原地 算法。

# 初步思路
说是用m*n的空间复杂度优化到m+n的空间复杂度+1的空间复杂度

O(m+n)其实也比较好想，就是准备两个数组，一个记录行，一个记录列，然后遍历一边，遇到0就i和j更新进去，就行了
```python 
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        """
        Do not return anything, modify matrix in-place instead.
        """
        m,n = len(matrix),len(matrix[0])
        row_set = set()
        col_set = set()
        #首先遍历一边，统计一下0出现的
        for i in range(m):
            for j in range(n):
                if matrix[i][j] == 0:
                    row_set.add(i)
                    col_set.add(j)
        #然后把set里面的所有的都弄成0
        for i in range(m):
            for j in range(n):
                if i in row_set or j in col_set:
                    matrix[i][j] = 0
        return matrix
            

```
