# 完全二叉树的节点数

给你一棵 完全二叉树 的根节点 root ，求出该树的节点个数。

完全二叉树 的定义如下：在完全二叉树中，除了最底层节点可能没填满外，其余每层节点数都达到最大值，并且最下面一层的节点都集中在该层最左边的若干位置。若最底层为第 h 层（从第 0 层开始），则该层包含 1~ 2h 个节点。
输入：root = [1,2,3,4,5,6]
输出：6

## 初步思路

遍历一遍是On的方法，更快的方法是利用完全二叉树的性质

首先，对于完全二叉树，如果是满的话，对于n层，那么就有2^(n-1)个节点

所以说，可以利用这个性质来去弄

我们首先需要准备两个函数，一个负责找到从当前node出发的层数（直接一直往左走到头就行）

然后一个find的主函数，我们的想法和二分差不多，首先是我们要去找到node.right的left

如果我们发现，node.right.left能够走到头，且层数是一样的，说明缺的在另一边，那么我们就继续递归find root.right就行，而且数量书

如果发现走到头后不是，那么说明缺的还在root.left的这一个分支，那么统计的层数-1，然后继续递归左就行

```python 
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def countNodes(self, root: Optional[TreeNode]) -> int:
        def mostleft(node,level):#不断往左，能到几层
            while node:
                level += 1
                node = node.left
            return level
        def find(cur,level,h):#h是整个树的层数
            if level == h:
                return 1
            #如果cur的右边往左扎到了最深
            if mostleft(cur.right,level) == h:
                #说明这棵树左边是满的，递归右边的就行
                return 2**(h-level) + find(cur.right,level+1,h)
            else:
                #左边不是满的，从左边招
                return 2**(h-level-1) + find(cur.left,level+1,h)
        if not root:
            return 0
        return find(root,1,mostleft(root,0))


```
