# 从前序和中序构造二叉树
给定两个整数数组 preorder 和 inorder ，其中 preorder 是二叉树的先序遍历， inorder 是同一棵树的中序遍历，请构造二叉树并返回其根节点。

输入: preorder = [3,9,20,15,7], inorder = [9,3,15,20,7]
输出: [3,9,20,null,null,15,7]

## 初步思路
前序是中左右，中序列是左中右，所以思路就是，我先拿到preorder的第一个，然后用这个去inorder里面找，在inorder里面的左边是左节点，右边是右节点，然后preorder缩左右切开，inorder也缩左右切开，然后preorder的左和inorder的左一起递归，右和右一起递归就行


```python 
# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right
class Solution:
    def buildTree(self, preorder: List[int], inorder: List[int]) -> Optional[TreeNode]:
        if not preorder:
            return None
        
        #根是preorder的第一个    
        root = TreeNode(preorder[0])
        #拿到root在中序的下表
        root_index = inorder.index(preorder[0])

        #分割，此时0-root_index-1是左的长度，root_index-len（inorder是右边的
        inorder_left = inorder[:root_index]#左臂右开
        inorder_right = inorder[root_index+1:]

        #分割,pre要按长度分割
        preorder_left = preorder[1:root_index+1]#左臂右开，这里是开头的1是root
        preorder_right = preorder[root_index+1:]

        #递归
        root.left = self.buildTree(preorder_left,inorder_left)
        root.right = self.buildTree(preorder_right,inorder_right)

        return root
        


```
