# 反转链表2

给你单链表的头指针 head 和两个整数 left 和 right ，其中 left <= right 。请你反转从位置 left 到位置 right 的链表节点，返回 反转后的链表 。

输入：head = [1,2,3,4,5], left = 2, right = 4
输出：[1,4,3,2,5]

输入：head = [5], left = 1, right = 1
输出：[5]


## 初步思路

初步的想法是，先跑到cur的位置，记录一下left和right的位置，然后中间的正常反转，反转的时候开始的那个东西next到right下一个，最后的那个东西next到

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
        if left == right:#边界条件，
            return head




        ans = head
        l = head
        for _ in range(left-2):
            l = l.next#这个是走到左边的头头
        l_begin = l#这个是l的前面
        l_end = l.next#这个是开始的位置,也是最后需要衔接到r_begin的左端
        l = l_end

        #下面找r
        r = l#开头的位置
        for _ in range(right-left):
            r = r.next
        r_end = r
        r_begin = r.next#这里的begin就是需要反转的外面

        #解释，l_begin,r_begin这两个是外侧的，不需要反转，只是为了最后接上去，l_end和r_end是需要开始的左右
        
        #先给左右两边的断开
        l_begin.next =None
        r.next = None
        #下面就是正常的反转链表
        begin = l
        cur = l
        pre = None
        while cur:
            _next = cur.next
            cur.next = pre
            pre = cur
            cur = _next
        #最后的pre是最后一个的新的头，这个需要连接到l_begin
        l_begin.next = pre
        #把begin链接到r的begin
        begin.next = r_begin
        return ans
            
```

## 进阶写法

可以写在一起，为了防止溢出，可以用一个虚拟节点

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseBetween(self, head: Optional[ListNode], left: int, right: int) -> Optional[ListNode]:
        p0 = dummy = ListNode(next = head)
        for _ in range(left-1):
            p0 = p0.next
        #然后正常的反转链表
        cur = p0.next
        pre = None
        for _ in range(right-left+1):
            _next = cur.next
            cur.next = pre
            pre = cur
            cur = _next
        #反转完后，cur其实就是之前我们提到的r_begin,即外围的，p0是之前所谓的l_begin,p0.next是l，pre是r，所以是接起来
        p0.next.next = cur#相当于把l接到r_begin
        p0.next = pre#相当于吧l_begin接到r上，
        return dummy.next
        

       
        

```
