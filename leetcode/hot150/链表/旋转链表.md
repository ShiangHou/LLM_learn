# 旋转链表

给你一个链表的头节点 head ，旋转链表，将链表每个节点向右移动 k 个位置。

head = [1,2,3,4,5], k = 2
输出：[4,5,1,2,3]

## 初步思路
首先k肯定是要先mod一下，先跑出n是多少

然后我们把收尾相连，断开倒数第k和第k+1的节点就行

断掉倒数k和k+1

比如1 2 3 4 5
k是2

断掉3 4之间

即正数3 和4 

n = 5

即n-k和n-k+1的位置

for 循环走n-k-1步，因为是从第一个开始走

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def rotateRight(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        #首先先遍历一边，拿到n和最后一个
        n = 1
        cur = head
        while cur and cur.next:
            cur = cur.next
            n+=1
        end = cur
        k = n%k
        #头和尾相连
        end.next = head
        #断掉倒数k和k+1个，就是正数n-k和n-k+1的位置
        cur = head
        for _ in range(n-k-1):
            cur = cur.next
        ans = cur.next#记录一下答案
        cur.next = None#段
        return ans



```
