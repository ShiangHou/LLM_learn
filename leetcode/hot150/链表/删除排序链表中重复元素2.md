# 删除排序链表中重复元素
给定一个已排序的链表的头 head ， 删除原始链表中所有重复数字的节点，只留下不同的数字 。返回 已排序的链表 。

输入：head = [1,2,3,3,4,4,5]
输出：[1,2,5]

## 初步思路
先弄一个虚拟头节点，

然后从cur开始，往下走，如果cur.next.val = cur.val

那么我们存一下这个cur.val,再往下写一个循环，知道找到不等于得node

然后cur.next = node，cur换成这个新的node，继续，就行

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def deleteDuplicates(self, head: Optional[ListNode]) -> Optional[ListNode]:
        dummy = ListNode(next = head)
        cur = dummy#从dumy开始
        while cur.next and cur.next.next:#dummy下一个和dummy下个
            value = cur.next.val#候选value，从第一个开始
            if cur.next.next.val == value:
                while cur.next and cur.next.val == value:
                    cur.next = cur.next.next#这个会连带着吧所以一样的都去掉，因为cur是上一个，
            else:
                cur = cur.next
        return dummy.next
```
