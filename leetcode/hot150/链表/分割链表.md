# 分割链表

给你一个链表的头节点 head 和一个特定值 x ，请你对链表进行分隔，使得所有 小于 x 的节点都出现在 大于或等于 x 的节点之前。

你应当 保留 两个分区中每个节点的初始相对位置。

head = [1,4,3,2,5,2], x = 3
输出：[1,2,2,4,3,5]

## 初步思路
弄四个变量，分别是l_head,l_tail,r_head,r_tail

l是用来记录比value小的，r是用来记录比value大的

然后最后是把l tail直接加到r head上

流程是，开始遍历，然后的话遇到小的就往一个里面塞，遇到大的就往另一个里面塞

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def partition(self, head: Optional[ListNode], x: int) -> Optional[ListNode]:
        l_head = None
        l_tail = None
        r_head = None
        r_tail = None
        cur = head
        while cur:
            #先存一下cur的下一个
            _next = cur.next
            cur.next = None
            temp_val = cur.val
            if temp_val < x:
                #如果还没建起来，就建一个
                if not l_head:
                    l_head = cur
                else:
                    l_tail.next = cur
                #最后把l_tail移动一下
                l_tail = cur
            else:
                if not r_head:
                    r_head = cur
                else:
                    r_tail.next = cur
                r_tail = cur
            cur = _next
        #最后链接一下
        if l_tail:
            l_tail.next = r.head
            return l_head
        else:#没有l_tail，直接返回r
            return r_head



```
