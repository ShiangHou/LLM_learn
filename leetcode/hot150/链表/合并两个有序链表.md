# 合并两个有序链表
将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。 




## 初步思路
依旧是准备两个变量，然后滑动，最后看一下谁没完谁再while一下

```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeTwoLists(self, list1: Optional[ListNode], list2: Optional[ListNode]) -> Optional[ListNode]:
        cur1 = list1
        cur2 = list2
        if not cur1 or not cur2:
            return cur2 if not cur1 else cur1#有空的直接判断
        #先拿到小的头
        head = cur1 if cur1.val <= cur2.val else cur2

        #把头直接移动到下一个
        if head == cur1:
            cur1 = cur1.next
        elif head == cur2:
            cur2 = cur2.next
        cur = head
        while cur1 and cur2:
            if cur1.val<= cur2.val:
                cur.next = cur1
                cur1 = cur1.next
                cur = cur.next
            else:
                cur.next = cur2
                cur2 = cur2.next
                cur = cur.next
        #最后谁不是空谁直接附在cur后面
        cur.next = cur1 if cur1 else cur2
        return head
```
