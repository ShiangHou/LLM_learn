# 两数相加
给你两个 非空 的链表，表示两个非负的整数。它们每位数字都是按照 逆序 的方式存储的，并且每个节点只能存储 一位 数字。

请你将两个数相加，并以相同形式返回一个表示和的链表。

你可以假设除了数字 0 之外，这两个数都不会以 0 开头。

## 初步思路
需要维持一个变量叫做carry，然后每次计算都要计算一下进位carry


```python 
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def addTwoNumbers(self, l1: Optional[ListNode], l2: Optional[ListNode]) -> Optional[ListNode]:
        #先弄两个变量来滑动
        cur1 = l1
        cur2 = l2

        carry=0#表示每次的进位
        dummy = ListNode()#虚拟头节点，最后返回这个的next就行
        cur = dummy#在最后的答案上滑动的
        while cur1 or cur2:
            n1 = cur1.val if cur1 else 0
            n2 = cur2.val if cur2 else 0
            temp_num = n1+n2+carry#一个上面的+另一个上面的和之前的进位
            num = temp_num %10#个位
            carry = temp_num //10#进位

            cur.next = ListNode(num)
            cur = cur.next
            cur1 = cur1.next if cur1 else None
            cur2 = cur2.next if cur2 else None

        #如果最后carry还有，就再加一个
        if carry != 0:
            cur.next = ListNode(carry)
        return dummy.next            



        

```
