# 同构字符串

给定两个字符串 s 和 t ，判断它们是否是同构的。

如果 s 中的字符可以按某种映射关系替换得到 t ，那么这两个字符串是同构的。

每个出现的字符都应当映射到另一个字符，同时不改变字符的顺序。不同字符不能映射到同一个字符上，相同字符只能映射到同一个字符上，字符可以映射到自己本身。

输入：s = "egg", t = "add"

输出：true

解释：

字符串 s 和 t 可以通过以下方式变得相同：

将 'e' 映射为 'a'。
将 'g' 映射为 'd'。

示例 2：

输入：s = "f11", t = "b23"

输出：false

解释：

字符串 s 和 t 无法变得相同，因为 '1' 需要同时映射到 '2' 和 '3'。

示例 3：

输入：s = "paper", t = "title"

输出：true

## 初步思路
首先是要求字符串的种类+各个种类的出现次数一样

可以构架两个字符串的dict
首先构建两个dict，存放映射关系

然后开始遍历两个字符串，如果没有这个映射关系，就存放，一下

如果有这个关系了，是相同的，那么就继续，如果有关系后，但是对应的映射不是的，那么直接return false

```python 
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s_dict = {}
        t_dict = {}
        if len(s)!=len(t):
            return false
        n = len(s)
        for i in range(n):
            if s[i] not in s_dict:#如果不在的话，构建映射表
                s_dict[s[i]] = t[i]
                t_dict[t[i]] = s[i]
            elif s[i] in s_dict and t[i] != s_dict[s[i]]:#如果之前有了，但是最新的这个t不是之前的那个
                return False
        return True


```
一个badcase是
s=
"badc"
t =
"baba"

一种情况，如果s[i]和t[i]的映射出现冲突

所以我们的判断只判断了一半，另一半也要判断

```python 
class Solution:
    def isIsomorphic(self, s: str, t: str) -> bool:
        s_dict = {}
        t_dict = {}
        if len(s)!=len(t):
            return false
        n = len(s)
        for i in range(n):
            if s[i] not in s_dict and t[i] not in t_dict:#如果都不在的话，构建映射表
                s_dict[s[i]] = t[i]
                t_dict[t[i]] = s[i]
            elif (s[i] in s_dict and t[i] != s_dict[s[i]]) or (t[i] in t_dict and s[i] != t_dict[t[i]]) :#如果之前有了，但是最新的这个t不是之前的那个
                return False
        return True
```
